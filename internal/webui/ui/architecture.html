Run a real task

Install Relay’s Go executable and use your existing Codex login. This path has been exercised end to end with actual Codex CLI runs.

go install ./cmd/relay-agent
printf 'Locate the Redis token bucket.' | relay-agent run --host codex --mode auto
relay-agent runs
relay-agent serve

Open http://127.0.0.1:8787 for the real run history. The page binds to loopback and reads only the local metadata log. No prompt or answer text is saved there.

Model selection

Explicit

--mode cheap and --mode strong select the configured model directly. Override model IDs per call. Use --model ID --effort LEVEL to select any model and reasoning level advertised by your Codex catalog. Unsupported pairs fail before launch.

Automatic

--mode auto maps simple, standard, and complex tasks to model/effort pairs: Luna/low, Sol/medium, and Astra/high by default. A routing file can assign any available model to each tier. It adds no API call. It is a heuristic, not a quality guarantee. Jev remains optional for the separate HTTP gateway, where its extra latency and cost can be justified and measured.

The Codex model picker

Installing Relay adds a skill and MCP tools. It does not add a Relay entry to Codex’s model dropdown or intercept every chat message. Use the plugin to route a bounded subtask, or the CLI to route a whole new task.

What the numbers mean

Codex emits turn-level input, cached-input, and output tokens in its JSON event stream. Relay records those values. It does not infer a subscription bill or claim that a smaller model used fewer tokens in general.

The older self-hosted Go API gateway is still available for applications that need normalized OpenAI, Anthropic, and Cohere requests, Redis quotas, fallback, and a PostgreSQL ledger. It is separate from native agent execution. The public website exposes neither provider credentials nor a simulated completion playground.

No paid provider API key is needed to use Relay with an already-authenticated Codex CLI. Relay has experimental Claude Code command and parser support, but Codex is the verified integration for this release.
