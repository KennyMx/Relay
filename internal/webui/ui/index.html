Relay selects a model and reasoning level from your Codex catalog before running a task. It captures the native CLI’s reported tokens and keeps a private, local history. No gateway account or provider API key is needed when you use your existing Codex login.

The workflow

A small layer around
Codex.

Relay is a launcher and recorder, not a replacement agent. It keeps Codex’s native behavior while making the model choice and usage visible.

01 / ROUTE

Pick a model for the task

--mode auto uses an offline heuristic. --mode cheap and --mode strong give you direct control. Use --model and --effort for any supported combination. relay-agent models reads your live catalog.

02 / EXECUTE

Run the native CLI

Relay starts a fresh Codex run. Read-only is the default; --write enables Codex’s normal file-edit workflow and approvals.

03 / INSPECT

Keep the evidence

Relay parses the native result and saves usage metadata in an ignored local log. Open the local runs page to inspect real sessions without saving prompts or answers.

Usage parserReads Codex-reported token and duration data.

Relay can route work to a lower-cost model, but token counts alone do not establish monetary savings. Codex subscription billing is not reported per run.
